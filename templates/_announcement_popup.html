Deliberately a plain fetch on page load, not a context processor: marking it "seen" only happens once this script actually runs client- side (see announcements.views.PendingAnnouncementView's own docstring for why -- a context processor would fire on every server render, including an htmx partial that never actually shows this dialog). Styled inline, not with either app's own component classes -- management (.modal/ .modal-box, assets/management.css) and mobile (m-card/pill-*, assets/mobile.css) are two different design systems, and this one partial has to render correctly in both without knowing which one it landed in. Native normally centers itself via the UA stylesheet's `margin: auto`, but both apps' own Tailwind preflight resets margin to 0 on every element -- including this one -- so centering is done explicitly below (fixed + transform) rather than relied on. {% endcomment %}
