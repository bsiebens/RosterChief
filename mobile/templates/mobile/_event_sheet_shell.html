{% load i18n lucide %} {% comment %} The bottom sheet an event opens in over Home and the Calendar (iOS: the EventReplySheet). Closed it is invisible and costs nothing; static/js/mobile-sheet.js opens it on any tap on an event link, fetches the event's own fragment (``?sheet=1``, mobile/_event_sheet.html) into #event-sheet-content and, once a sheet has been used to answer something, refreshes the screen underneath when it closes. Without JavaScript the same links are plain links to the full event page. {% endcomment %}
