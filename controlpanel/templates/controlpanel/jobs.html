{% lucide "info" size=16 class="inline -mt-0.5 mr-1" %} These run on an in-process scheduler inside the web container (schedule: JOB_REGISTRY in features/jobs.py; see "Scheduled jobs" in DEPLOYMENT.md). Only one process ticks at a time, and a run still going makes its next tick skip rather than queue. "Run now" runs a job once in the background — the page doesn't wait, refresh for the result — and a paused job refuses it until resumed. A run that never shows up at its scheduled time (not paused, no maintenance, no earlier run still going) points at the web container's scheduler — check its logs — not at this page.
