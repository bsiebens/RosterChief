Matching headings share icons. **Status** uses Activity, **Details** uses Clipboard List, **Invoice** uses Receipt Text, **Payments** uses Banknote, and **Line items** uses List Ordered. The team and member **Attendance rate** cards use Calendar Check, while jersey numbers use Hash.
