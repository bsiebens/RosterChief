{% comment %} Three fixed-height columns (lg+ only -- below that they stack full-width at their natural height, since a hard pixel height on a narrow viewport would just clip things). The grid row itself carries the fixed height; each column div is a grid item, so CSS Grid's own default (align-items: stretch) fills it to that height with no extra markup. Every card inside then claims a flex share of its column via flex-1/flex-[3] rather than an explicit height, so the split holds regardless of how much content each one actually has -- the point of "fixed" here is the page stops growing/shrinking as counts change, not that every card is the same height as its neighbours. Anything that could genuinely overflow (Needs attention's item list, Upcoming's event list, News's list) scrolls internally (overflow-y-auto + min-h-0, the standard fix for flex children ignoring their own height cap) rather than pushing the column taller. {% endcomment %}
